# EasyControl 路线图

## 阶段 0：立项（已完成）

- 明确固定双设备、办公场景、低延迟和完整无人值守目标。
- 确认配对、独立解锁密码、会话重连和自动锁定规则。
- 完成低成本网络方案官方资料调研，不预设品牌。

## 阶段 1：关键技术验证（已授权启动）

Intranet 热点测试暂停期间，用户已明确授权 EasyControl 并行开始技术验证。

按 [技术验证计划](validation.md) 完成 V0–V4。最先判断现有 Tailscale 问题所在，再决定编码、权限和网络方案，不先扩大产品功能。

**阶段出口**：验证报告经用户审查，明确批准进入第二阶段。

## 阶段 2：完整产品落地

1. 被控端服务、控制端连接和基本画面/输入闭环。
2. 配对、加密、本地解锁、自动锁定和会话恢复。
3. 登录界面、锁屏、常规 UAC 与 Windows 自启动。
4. 纯文本剪贴板、网络路径与延迟诊断。
5. 双端基本界面、托盘、安装包、卸载和安全配置路径。

界面以实用为准，但已确认功能必须实际落地，不能把技术 demo 当作第二阶段完成。

## 阶段 3：真实使用验收

- 至少 7 天日常远程工作，覆盖实际使用的香港、深圳、广州网络。
- 完成 8 小时连续会话、断网恢复、重启和无人值守检查。
- 记录并关闭阻塞问题，保留网络限制与用户已接受的取舍。

## 暂不安排

多用户、多被控设备、游戏级画质、4K 60 FPS、公共控制平台和复杂自建控制面不进入当前路线。
