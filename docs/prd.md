# EasyControl 产品需求

## 核心承诺

用户使用自己的手提电脑，跨城市稳定控制一台固定台式电脑，完成编程、浏览器、文件管理和普通办公；画面以清楚可用为准，优先输入响应和连接恢复。

## 用户、设备与场景

- 只服务一台固定控制端和一台固定被控端，不做多用户或设备管理平台。
- 被控端通常在香港，控制端会在香港、深圳和广州的真实网络中使用。
- 首版面向单台主显示器、1080p、办公场景最高 30 FPS。
- 不以大型游戏、高帧率视频、专业剪辑或 4K 60 FPS 为目标。

## 功能范围

### 画面与控制

- 被控端采集画面，控制端显示并回传鼠标、键盘。
- 文字清晰优先于高画质；网络或编码不足时自动降低帧率、质量或分辨率。
- 采用最新画面优先策略，不持续积压旧帧。
- 支持双向纯文本剪贴板，不支持图片或复杂剪贴板格式。
- 文件传输复用 Intranet，不在 EasyControl 内建立第二套文件同步系统。

### 无人值守

- 被控端重启后仍可远程连接，不要求本地人员启动程序。
- 必须覆盖 Windows 锁屏、登录界面和常规 UAC 确认窗口。
- Ctrl+Alt+Del 等特殊组合键单独验证，不混入普通 UAC 承诺。

### 身份与安全

- 两台设备配对并使用加密连接，不只依赖简单密码或虚拟网络成员身份。
- 不主动配置公网端口映射，不开放仅凭简单密码即可控制的公网端口。
- 每次主动访问前，控制端必须输入独立的 EasyControl 本地解锁密码。
- 不保存或要求输入 Windows 账户密码来完成 EasyControl 解锁。
- 同一已解锁会话的短暂断网自动重连不重复输入密码。
- 重启控制端、手动断开后重连、主动锁定、更换设备或清除配对后必须重新解锁。
- 控制端连续 15 分钟无本地键盘或鼠标输入后自动锁定并断开；时间可调，被控任务继续执行。

### 网络与诊断

- 不预设网络品牌，根据直连比例、P95/P99 延迟、丢包和重连实测选择。
- 先测现有 Tailscale；稳定直连则保留，长期中继先检查 NAT、CGNAT、UDP、防火墙和端口映射。
- 必要时同条件比较 ZeroTier、NetBird；都只能中继时再比较 Peer Relay 与 WireGuard + VPS。
- 首阶段不自建完整 DERP、Headscale 或 NetBird 控制面，不急着购买 VPS。
- 显示网络路径、直连/中继、RTT、丢包和重连状态，故障不能只显示“连接失败”。

## 明确不包含

- 多用户、多被控设备、公网开放访问和通用远程控制平台。
- 游戏级画质、4K 60 FPS，以及首版多显示器切换。
- 第一阶段完整产品外壳；双端界面、托盘、自启动和安装包属于第二阶段。
- 未经实测就承诺任何网络品牌在香港与内地之间必然低延迟。

## 验收指标

- 在 RTT ≤ 30 ms 且线路稳定时，输入到画面反馈的端到端延迟 P95 ≤ 100 ms。
- 连续远程控制 8 小时，无程序导致的死锁、崩溃或必须重启才能恢复的问题。
- 短暂断网后，网络恢复 10 秒内自动重连，不要求重新填写地址或密码。
- 重启、锁屏、登录界面和常规 UAC 下均可恢复控制。
- 第二阶段完成后至少 7 天真人使用，覆盖实际会使用的地点和网络；不再依赖 Windows RDP 完成日常远程操作。
- 若实测无法达到承诺，必须展示证据并由用户决定调整目标、改用其他网络路径或停止，不隐瞒限制。
